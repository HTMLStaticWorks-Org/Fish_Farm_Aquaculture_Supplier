# AquaHarvest — Fish Farm & Aquaculture Supplier Website

Responsive multi-page HTML5/CSS3/JavaScript website engineered for commercial aquaculture, modern fish hatcheries, and pond equipment suppliers.

## Features
- **Pages**: Home 1, Home 2, About, Products (3x3 grid), Photo Gallery, Farming Guide, Contact Us, Login, Signup, and Forgot Password.
- **Theme & Direction Support**: Dark / Light mode toggle and RTL / LTR direction toggle with instant state persistence (`localStorage`).
- **Responsive Layout**: Fluid breakpoints optimized for Desktop (>1024px), Tablet/iPad (768px-1024px), and Mobile devices (<768px) with accessible hamburger drawer menu.
- **High Contrast Typography**: Tuned for maximum WCAG accessibility across both light and dark modes with static aquaculture brand styling.
- **Interactive Elements**: Sticky navigation, back-to-top floating button, interactive product filters, demo auth forms, and OpenStreetMap embed.
